# ShitCam VS Code Extension

Syntax highlighting and language support for the **ShitCam** programming language (`.sc`).

## Installation

Copy or symlink this folder into your VS Code extensions directory:

```bat
xcopy /E /I editors\vscode "%USERPROFILE%\.vscode\extensions\shitcam-syntax-0.1.0"
```

Restart or reload VS Code, and any `.sc` file will automatically receive full syntax highlighting!
